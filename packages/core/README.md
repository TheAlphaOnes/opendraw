# @opendrawjs/core

The opendraw **engine**: the element model, geometry, scene document with history, hit testing, transforms, binding and elbow-arrow routing, the rough.js renderer, and PNG/SVG/JSON export. It has no DOM framework and no UI.

```bash
npm install @opendrawjs/core
```

Most apps want an editor package instead: [`@opendrawjs/nuxt`](https://www.npmjs.com/package/@opendrawjs/nuxt) (Vue/Nuxt), [`@opendrawjs/react`](https://www.npmjs.com/package/@opendrawjs/react), [`@opendrawjs/svelte`](https://www.npmjs.com/package/@opendrawjs/svelte), or the framework-free [`@opendrawjs/editor`](https://www.npmjs.com/package/@opendrawjs/editor).

Full documentation: [https://github.com/TheAlphaOnes/opendraw](https://github.com/TheAlphaOnes/opendraw#readme)
